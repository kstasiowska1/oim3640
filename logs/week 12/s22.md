## What I learned today [Brief reflection on key concepts; focus on understanding, not just syntax]
- How to make my own html file (folder = www, file = index.html, right click index.html --> reveal in file explorer --> open file)
- How to organize a website using different html tags
- Common HTML tags
    - <h1> to <h6>: Define page headings, with <h1> being the most important.
    - <p>: Creates a paragraph of text.
    - <a>: Defines a hyperlink; use the href attribute to specify the destination URL.
    - <img>: Embeds an image; it is a "self-closing" or void tag that does not need a closing tag.
    - <div>: A generic block-level container used to group elements together for styling.
    - <ul> / <ol> / <li>: Used to create unordered (bulleted) or ordered (numbered) lists.
