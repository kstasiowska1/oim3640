## What I learned today [Brief reflection on key concepts; focus on understanding, not just syntax]
- Simple commands for terminal:
    - cd folder : change directory (go into a folder)
    - cd … : go up one level
    - dir : list files in current folder
    - mkdir folder : make new folder
    - pwd : print working directory (where am I?)
- How to run/open Python files in VS Code
    - in VS Code terminal, type "cd code" --> enter
    - type "python [file name.py]"
- Press "d" twice to delete something
- Open jupyter labs notebook in browser
    - go into GitHub Desktop
    - repository --> Open in Command Prompt
    - type "cd code" --> enter
    - type "notebooks jupyter notebooks"
- Ctrl "C" in terminal closes what you are doing
- when Professor says "open terminal", open the regular terminal on you desktop
- Ctrl -> Shift makes any line a comment
