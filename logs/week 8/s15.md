## What I learned today [Brief reflection on key concepts; focus on understanding, not just syntax]
- Tuples:
    - Similar to lists but immutable (cannot change values)
    - Use () instead of []
    - Can access like lists (indexing)
    - Useful when values should not change
    - zip() combines two sequences
        - ex. names = ['AAPL', 'GOOG', 'MSFT']
              prices = [182.30, 141.80, 415.20]
              for name, price in zip(names, prices):
                  print(f'{name}: ${price}')
- Difference vs lists:
    - Lists -> can modify (append, change values)
    - Tuples -> fixed / read-only
