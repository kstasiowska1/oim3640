## What I learned today [Brief reflection on key concepts; focus on understanding, not just syntax]
- operators that work on strings and list
    - indexing
    - + (concatenation)
    - [:] (slicing)
    - * (repetition)
    - len()
- Strings are immutable, strings are mutable
- Use '___.append' to add to a list
- 'sorted()' doesnt change the original list, but will sort it
- '___.sort' will change the original list
- Dictionaries
    - Keys must be unique
    - Ex. eng2sp = {'one': 'uno', 'two':'dos', 'three':'tres'}
        - eng2sp['one'] --> 'uno'
    - Start empty
        - Ex. prices = {}
                prices['APPL'] = 178.50
                prices['GOOG'] = 141.80
                prices['MSFT'] = 415.20
            - Can be updated by overwriting
            - Can be deleted using 'del prices['GOOG']
    - Parts of the dictionary are "items"
