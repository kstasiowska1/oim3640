# Chapter 1 — Programming as a Way of Thinking
- Programming teaches you how to think like a computer scientist.
- This way of thinking combines math, engineering, and science.
- Python is used to represent numbers, letters, and words.
- Key vocab: operator, expression, value, type.

## Arithmetic Operators
- `+` add, `-` subtract, `*` multiply, `/` divide.
- Division returns a float.
- `//` is integer (floor) division.
- `**` is exponentiation.
- `^` is NOT exponentiation in Python.

## Expressions
- Expressions combine numbers and operators.
- Python follows order of operations.
- Parentheses change the order.
- Every expression has a value.

## Functions
- Functions like `round()` and `abs()` work with numbers.
- Parentheses are required.
- Leaving them out causes a syntax error.

## Strings
- Strings are sequences of characters in quotes.
- Can use single or double quotes.
- `+` joins strings.
- `*` repeats strings.
- `len()` returns string length.
- Must use straight quotes.

## Values and Types
- Common types: `int`, `float`, `str`.
- `type()` shows a value’s type.
- `int()` and `float()` convert values.
- Strings with digits are still strings.
- Using wrong types causes `TypeError`.
- Use underscores for large numbers.

## Formal vs Natural Languages
- Natural languages are ambiguous.
- Formal languages are precise and literal.
- Small errors matter a lot in Python.

# Chapter 2 — Variables and Statements

## Variables
- A variable is a name that refers to a value.
- Assignment uses `=`.
- Assignment statements have no output.
- Variables can be used in expressions and functions.

## State Diagrams
- Show variables pointing to values.
- Help explain how Python stores data.

## Variable Names
- Can contain letters, numbers, and underscores.
- Cannot start with a number.
- Use lowercase by convention.
- Keywords cannot be variable names.

## Import Statement
- Some features must be imported.
- A module is a collection of variables and functions.
- Use dot notation to access module values.

## Expressions vs Statements
- Expressions have values.
- Statements perform actions.
- Evaluation = computing a value.
- Execution = running a statement.

## Print Function
- Only the last expression is shown automatically.
- `print()` displays values.
- Can print multiple values separated by commas.

## Arguments
- Arguments are values passed into functions.
- Some functions take one, many, or optional arguments.
- Wrong number or type causes `TypeError`.

## Comments
- Comments start with `#`.
- Used to explain code in natural language.
- Best comments explain *why*, not *what*.

## Debugging
- Syntax errors: structure is wrong.
- Runtime errors: program crashes while running.
- Semantic errors: program runs but gives wrong results.
