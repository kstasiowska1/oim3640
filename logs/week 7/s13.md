## What I learned today [Brief reflection on key concepts; focus on understanding, not just syntax]
- Strings review:
    - Strings are immutable, if you want to add something to a string, make a new variable
    - Using '_____.lower()' makes temporary changes to the list, does not replace the old values in the string
    - Using '_____.find(_____)' will return the first occurence of something
    - 'strip()' only affects characters at the very beginning and very end of the string, characters in the middle remain untouched
    - when you have a list of items and want to print it out in a nice format: ', 'join(x)
    - Converts a list of strings to one string: ''.join(X)
    - To make an unformated string a list: 'variable = x.split(' ')'

- In text files, there is always an invisible '\n' to start a new line
- Append only works for a list

- Lists:
    - Stores multiple values
    - Can be accessed in the same way as strings
    - Use '___.append()' to change the list
