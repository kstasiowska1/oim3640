## What I learned today [Brief reflection on key concepts; focus on understanding, not just syntax]
- In an if statement, the order of conditions is important
    - If the first condition is true, it will return or print the first result, regardless of the others
    - Ex. if score >= 60:
                print ("Pass")
            elif score >= 90:
                print("A")
            else:
                print("Fail")
        - this will print "Pass"
- Return will immediately end the if/else/elif function!!!
- An if statement cannot have another if statement under it, it will be a separate if statement
    - need "elif"
- Selecting a line and doing Alt --> arrow key will allow you to move it up or down
- if __name__=="__main__":
    main()
    - this is the starting point of understanding a coding file
- "and": if both statements are true, it is true
- "or": if one statement is true, it is true
- if you know the count, use "for" but if you're waiting for a condition, use "while"
- break finishes/stops a while loop
- continue makes the while loop continue to the next iteration (ex. word in the list)
- list: storing multiple values in one variable
    - ex. words = ["hello", "world", "target", "python"]

- Precedence of python operators: defines the order in which Python evaluates different operators in a complex expression. Operators with higher precedence are executed first.
    - Rule of Thumb: Follows the PEMDAS order from mathematics (Parentheses, Exponents, Multiplication/Division, Addition/Subtraction).
    - Purpose: Ensures consistent, accurate, and predictable evaluation of formulas.
