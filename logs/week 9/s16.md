## What I learned today [Brief reflection on key concepts; focus on understanding, not just syntax]
- List: Mutable, 
- Dictionaries: Mutable, key to value, counting
- String: Immutable
- Tuples: Immutable
    - Let functions return more than one value
    - Can replace lists to make dictionary keys
    - Ex. def min_max(numbers):
              return min(numbers), max(numbers)
          lowest, highest = min_max([3, 1, 4, 1, 5])
        - The return creates a tuple -> unpacking assigns both at once: lowest = 1, highest = 5
- You cannot use a mutable type as dictionary keys
- Using a list is a good idea for creating a compound key
- [] = list
- () = tuple
- {} = dictionary
- use 'set()' when you want to get something unique
    - are faster
