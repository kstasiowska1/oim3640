## My Project Proposal

**What I'm building:** 
A Flask web app that takes a location input fomr the user and finds the nearest MBTA station using APIs.

**Why I chose this:** 
I want to learn how to build a web app and see what the code looks like behind the scenes. I also want to incorporate APIs to learn how to use them and to bring real-time data in.

**Core features:**
- A simple web app where the user can enter a location
- Use the Mapbox API to convert the location into coordinates
- Use the MBTA API to find the nearest station

**What I don't know yet:**
- How to fully test for and handle all errors, especially if I have not encountered all of them
- How to make the web app look more appealing and improve the user interface
- How I could expand this project with more features, like showing multiple nearby stations, the distance from the station, or adding a map
