## My Project Proposal

**What I'm building:** A Python text analysis app that analyzes real estate listing descriptions and finds common word patterns.

**Why I chose this:** I am interested in real estate and I wanted to build on my mini project 1 which is a house flip deal analyzer. I thought it would be interesting to see what words show up the most in property listings and how houses are described.

**Core features:**
- Load real estate listing text from a file
- Count word frequencies using a dictionary
- Print the top 10 most common words
- Show basic text stats like total words and unique words
- Help identify common patterns in real estate language

**What I don't know yet:**
- How to clean the text in a simple way
- How to remove punctuation correctly
- How I should compare common words in a useful way
- How to turn the word counts into a visualization later
